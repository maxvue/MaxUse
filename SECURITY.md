# Security Policy

## Supported Versions

Only the latest major and minor release receives active security patches.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within `@maxvue/max-use`, please report it responsibly rather than opening a public issue on GitHub.

1. **Email**: Send vulnerability reports directly to the maintainer at `johnattas@engeapp.com.br` or submit via GitHub Private Vulnerability Reporting.
2. **Details**: Include a description of the issue, proof of concept (PoC), and potential impact.
3. **Response Time**: We aim to acknowledge reports within 48 hours and release fixes in a timely manner.
